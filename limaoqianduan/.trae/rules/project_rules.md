# 项目规则

## 布局和UI设计规则（最高优先级）

1. **绝对不要修改现有布局**：除非用户明确要求修改布局，否则禁止对页面的整体布局、组件排列、区域划分做任何改动。修Bug就只修Bug的逻辑，不动布局。
2. **不要自作主张"优化"UI**：不要因为觉得"重复"或"不美观"就擅自合并、删除、移动UI元素。用户的每一个设计都是有意为之的。
3. **只改用户要求改的部分**：用户说修A就只修A，不要顺带改B、C、D。

## AI页面特定规则

- 顶部栏的模型下拉框是用户专门设计的模型切换入口，不要删除或改动
- 侧边栏"自定义模型"区域是添加/管理模型的入口，不要删除或改动
- 模型选择在顶部下拉框完成，模型管理在侧边栏完成，两者职责不同，不要合并
